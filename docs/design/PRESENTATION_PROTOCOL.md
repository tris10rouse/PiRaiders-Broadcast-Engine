# Managed native presentation session (implementation contract)

The host is a loopback-only HTTP/Socket.IO sidecar using the existing SPX-native slideshow assets and renderer. It does not replace SPX's controller, projects/rundowns/lifecycle or OGraf, and does not start a sender. A separate loopback origin avoids inheriting the upstream application's broad CORS/static/session routes. Default launcher integration and CasparCG URL loading remain next work.

## Factory and ownership

`await createPresentationHost({snapshotDir,port:0,commandTimeoutMs:12000,controllerOptions:{mode,intervalMs,transition,maxQueue}})` returns `{origin,getProgramURL,dispatch,snapshot,close}`. Only trusted Node code calls dispatch with an action STRING; input objects/signals are rejected. Use existing SlideshowController for bounded queue/Stop priority/timing. The factory owns the controller and the verified initial snapshot-media-handler. No arbitrary frame/source or browser-originated controller command is accepted. Factory returns no public renderer/socket/controller object and snapshot never contains credentials. `getProgramURL()` is credential-bearing and must not enter logs; future launcher passes it privately to a producer. Initial and recovered controllers are stopped; readiness is not playback. No Reload/source I/O after startup in this increment.

Disconnect/command timeout/invalid protocol rejects all pending operations and closes/replaces the controller with a fresh stopped instance, preserving committed deck/mode/settings. Renderer state becomes unverified; no automatic replay. Reconnection requires explicitly reopening getProgramURL() (ordinary reload has no fragment credential and remains inert) and successful initial black acknowledgment, then explicit Launch0. A disconnected browser must black itself, cancel pending work and never automatically reconnect. Controller state is not output/NDI/receiver evidence.

## HTTP/auth

Bind only127.0.0.1, generated ephemeral port by default. Request Host must equal actual loopback origin host; Origin on session POST and Socket.IO must equal actual origin; other requests with Origin must also match; remote peer must be loopback and Sec-Fetch-Site may be absent, none or same-origin; reject same-site and cross-site. Ignore forwarded headers. Serve only exact native template asset paths; no arbitrary filesystem/static cache. POST `/piraiders/session` requires `Authorization: Bearer <32-byte random base64url capability>` and empty body; issues a distinct random HttpOnly SameSite=Strict cookie `piraidersPresentation_<random-host-suffix>=<value>; Path=/piraiders/` (random name avoids cross-port cookie collisions; cookies are not port scoped). Cookie is required for image serving and Socket.IO handshake; token additionally required in Socket.IO auth. No CORS, private/no-store, nosniff, same-origin resource policy/referrer policy; reject unauthorized/invalid HTTP without private details. Node server header/request/idle/socket counts/timeouts bounded. Capability only appears in program URL fragment `#piraiders=<43-base64url-chars>`; browser removes fragment with history before any async work, POSTs capability as header, then connects.

Existing SLIDESHOW.html loads presentation-client.js. It is inert without exact managed fragment, preserving original SPX globals/lifecycle. An explicit navigation back to getProgramURL() may change only the fragment of the redacted URL; a hashchange listener recognizes only that exact managed fragment and reloads a fresh document for bootstrap. history.replaceState does not trigger this listener, and ordinary fragment changes or disconnects never cause a retry. An ordinary reload after redaction remains inert. In managed mode it uses existing piraidersRenderer only; no deck/timer/source discovery. Managed global SPX lifecycle calls must not become a second writer (reject Play/Continue/Update; Stop terminates managed session and blacks). No audience UI added.

## Socket.IO v4 wire

Path `/piraiders/socket.io`, websocket transport only, no automatic reconnection, max payload16KiB, bounded heartbeat. Client library served at `/piraiders/socket.io/socket.io.js`. Handshake auth `{token}` plus cookie; reject second program socket without evicting first. Host emits `init:{epoch:<uuid>}`. Client blacks and waits two animation frames (bounded), then emits `ready:{epoch}`. Host becomes ready only for exact epoch/current socket. Initialization deadline uses commandTimeoutMs. Browser-side no pending command before ready.

Host emits `command:{epoch,id:<positive safe integer>,type:'show',src,transition}` or `{epoch,id,type:'black'}`. Browser only accepts strict shapes/current epoch/monotonically increasing IDs, bounded to one show plus black. A show calls native renderer.show and acknowledges only after its promise (decode/transition/paint) resolves. Black aborts all pending shows, calls renderer.black and waits two animation frames. Client emits `ack:{epoch,id,ok:true}` or `ack:{epoch,id,ok:false,code:<fixed renderer code>}`. Never send exception strings. Host matches exact pending command and ignores stale/duplicate/wrong-epoch acknowledgments; schema violations from current socket fail session closed. Output state is frame/black only after valid successful acknowledgment; otherwise retain last acknowledged frame for ordinary load failure or mark unverified on session loss.

Host emits `cancel:{epoch,id}` on aborted show; client aborts matching pending native show. Node adapter stays pending until actual ack/connection loss/deadline, preserving the controller orphan barrier. In this host API there are no caller AbortSignals: show cancellation occurs for priority Stop/close/timeout, each requiring black or session teardown. Stop can overlap only the canceled show and one black; repeated Stops coalesce in the existing controller. After Stop's black ack, no late show may relight. Deadlines terminate/disconnect the session and require fresh Launch rather than dispatch around uncertain work.

Host emits `shutdown` on close; client blacks/cancels/disconnects. Transport disconnect, connect_error, protocol failure, asset/bootstrap failure or page lifecycle exit blacks/cancels without automatic retry. Native render abort/generation/paint watchdogs remain authoritative locally. Network loss cannot prove receiver black; report unverified, never NDI/on-air success. Server close is bounded/idempotent and releases timers/sockets.

Diagnostic renderer.lastError retains a fixed session error code through failed/reconnecting state and clears only after new initial black acknowledgment. It never contains raw exceptions or credentials. Initial HTML has a black inline fallback; managed readiness requires the actual slideshow stylesheet and critical viewport/image layout, so stylesheet/asset failure cannot report ready with white or uncontrolled output.

## Managed Reload and feedback increment contract

Host adds `reloadSnapshot(absolutePreparedSnapshotDir)`, `prepareTimeoutMs` default30000 (100..120000) factory option, and frozen snapshot `reload:{state,lastError}` plus `media:{registered,retained}` (counts only, no private paths). Reload returns fixed `{action:'reload',ok,code?}`; exactly one preparation/activation/retirement admission exists, BUSY otherwise. Snapshot handler accepts optional AbortSignal and passes it to full loadSnapshot; actual decoder/descriptor settlement, not ignored late promises. Factory defaults and initial snapshot behavior otherwise preserved.

Maintain an active handler plus at most one candidate/retiring handler, routes selected by exact snapshot UUID. Prepare while old deck/Auto remains live. Capture reload generation/controller/epoch. Stop/loss/close/new program epoch invalidates generation, aborts verification, clears pending feedback and never waits to request black. Late verification closes its handler without activation. Candidate handler remains registered through actual frame RPC refs; decrement only on actual ack/disconnect/deadline, not early controller CANCELLED. Promotion only after replaceDeck success and matching generation/controller; otherwise retain old active and retire candidate only at refs0. Block new Reload while worker/retiring refs persist. Reset controllers from committed active deck. No source/cache deletion or writes, no watcher/Google API/active-pointer file.

Stopped/offline Reload may prepare/replace the deck without rendering or visible feedback; next Launch0 uses it. Preparation errors/timeouts leave old Auto timer unchanged. Actual replacement render failure suspends Auto per existing controller. Program-epoch changes cancel old requests rather than applying them to a new renderer.

Controller adds optional renderer.feedback({mode?,reload?,signal}) and public setReloadState('loading'|'complete'|'failed',{signal}={}). Existing adapters without feedback retain immediate mode semantics. With feedback, playing mode changes compute target at dequeue and commit only after ACK. Stopped mode intent commits without visible RPC. Reload feedback is queued normal work, does not alter deck/index/mode or reset/suspend existing Auto timing on success; failures preserve existing playback timing (host transport uncertainty invalidates separately). Same cancellation barrier/watchdog and priority Stop apply. Public results use action:'feedback' with fixed failures; invalid states/options/signals rejected safely.

Wire adds strict `command:{epoch,id,type:'feedback',mode? ,reload?}` with at least one allowed field. mode auto/manual, reload loading/complete/failed only. Client applies native feedback and ACKs after bounded2RAF, one normal operation + priority black. Black/cancel abort feedback paint and clears overlays; negative/stalled feedback ACK invalidates session as unverified. Host binds renderer.feedback to same rpc path. No separate unbounded RPC queue: one latest Reload feedback intent and at most one queued/active operation, stamped generation/controller/epoch, coalesces obsolete intents and retries BUSY only on controller progress. Stop/loss/close clears/aborts that slot; stale callbacks cannot restore labels. Feedback is invisible while stopped/black. No volatile delivery.

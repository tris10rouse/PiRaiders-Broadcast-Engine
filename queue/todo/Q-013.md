Found by 5f-2 (fence 99). README-WINDOWS.md says manifest verification must come before configuration, and the operator checklist's first step is "Check the download", but the ZIP ships no command for it: only CI calls `verifyManifest` (`scripts/lib/windows-bundle.cjs`) on the extracted folder. Today the operator can only compare the ZIP's SHA-256 with its sidecar.

Success criteria: a root entry (for example `Verify-PiRaiders.cmd`, bundled Node only, no arguments) checks every extracted file against `BUILD-MANIFEST.json` before any operator file exists and prints one JSON line of fixed codes (ok, or which kind of difference: missing, changed, extra; no paths); the checklist's step 1 and README-WINDOWS.md name it; Linux tests on a built inventory (changed, missing and extra file each refused); the hosted-Windows run of the entry belongs to 5f-3's job if it has not landed yet, or a later row.

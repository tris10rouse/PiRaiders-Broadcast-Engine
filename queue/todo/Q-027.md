### This part's success criteria (written 2026-11-27, before the work)

1. Setup and Diagnose report whether this PC has the Microsoft x64 VC++ runtime Caspar needs (fixed codes, no paths). Diagnose only reports.
2. When it is missing, Setup asks "Install the Microsoft Visual C++ Runtime now? (Y/N)" and runs runtime/vcredist/VC_redist.x64.exe only on Y (Windows then asks for an administrator); N, no answer or a non-interactive run installs nothing and prints VCRUNTIME_MISSING with the one-line next step. The installer's exit code is reported as a fixed code; nothing is downloaded.
3. README-WINDOWS.md and OPERATOR-CHECKLIST.md gain the one prep step. Linux tests with stand-ins (prompt, refusal, runner); hosted Windows has the runtime installed, so the missing path on a clean PC is a manual gate, written as such.

### Found by Q-009 (fence 86), outside that row

Q-009 added `POST /game-day/api/end-dead` (manager `endDeadEvent`): it ends only an active event whose renderer is past the supervisor's restart limit (`runtime.restartsExhausted: true` in the state answer); anything else answers `409 EVENT_NOT_DEAD`. The Game Day page has no control for it, so the operator still cannot use it from the page. Design note: `docs/design/GAME_DAY_DIAGNOSTICS.md` › Ending a dead event (Q-009).
